## 浏览器集成

当前干净发布候选已在 macOS 上使用 Playwright 1.62.1 / Chromium 151 验收通过：空种子启动、8 条合成收藏分类、六家 AI 设置与模拟响应、编辑写回、删除取消和恢复、并发修改保护、标题点击及键盘跳转、独立详情弹窗、图谱及窄屏布局。页面错误列表为空。窄屏测试等待异步布局重排完成后再检查。

浏览器测试使用临时 Chromium 配置。六家 AI 返回值均为模拟；测试 Key 为明确的假值。它不依赖日常 Chrome 配置，也不验证所有 Chrome、Edge 或操作系统版本。

## 真实服务小样本

DeepSeek Flash 曾完成一次连接请求和三次公开示例分类请求，合计 672 token。Python 官方教程被归入编程类，Figma 被归入设计类；信息不足的示例保留待分类。

该测试复用插件的接口适配器、分类提示词及结果校验器，由独立进程请求官方服务。它不是浏览器内完整的真实 Key 流程，不代表批量分类准确率。其他五家服务尚未做真实账户调用验证。密钥、账户信息及原始账单不随项目发布。

## 发布检查

`scripts/check-release.cjs` 检查完整文件白名单、空种子、权限和常见密钥模式；存在 Git 仓库时也检查已跟踪文件。演示图必须使用合成数据并人工查看。检查脚本无法证明任意内容都不含敏感信息，新增测试样本和文档仍需人工审查。

暂未验证长期内存表现、跨浏览器互同步和完整数据备份迁移。CI 配置已提供，远端运行结果以 GitHub Actions 为准。
